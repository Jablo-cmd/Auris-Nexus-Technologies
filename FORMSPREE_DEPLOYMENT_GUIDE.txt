## TROUBLESHOOTING

### Issue: Form action still shows "/contact-submit.php"

**Cause:** Browser cache

**Solution:**
1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
2. Clear site data: Settings → Cookies and site data → Clear all
3. Try incognito window: Ctrl+Shift+N
4. Wait 5 minutes (CloudFlare/CDN cache)

---

### Issue: Form submits but no success message

**Cause:** JavaScript not updated or not loaded

**Solution:**
1. Check: File Manager - is js/main.js uploaded?
2. Verify: File size is correct (should be ~5 KB)
3. Hard refresh browser
4. Check console (F12): Look for JavaScript errors
5. Verify: Form action in HTML is correct

---

### Issue: Success message shows but no email arrives

**Cause:** Formspree receiving but forwarding failed, or email goes to spam

**Solution:**
1. Check: Formspree dashboard - submission appears?
2. If yes: Email delivery issue
   - Check info@aurisnexus.co.za spam folder
   - Check email server status (HOSTAFRICA mail)
   - Verify email address is active in cPanel
3. If no: Formspree not receiving
   - Check form endpoint (should be https://formspree.io/f/maewdqve)
   - Verify form UUID is correct
   - Test endpoint manually with curl
   - Contact Formspree support

---

### Issue: "Could not reach the server" error

**Cause:** Network issue or endpoint unavailable

**Solution:**
1. Check: Internet connection
2. Verify: https://formspree.io is accessible
3. Check: Browser console for CORS errors
4. Verify: HTTPS is working on aurisnexus.co.za
5. Test: Direct endpoint access: https://formspree.io/f/maewdqve
   - You should see a 405 Method Not Allowed (that's correct for GET)
6. If no response: Contact HOSTAFRICA support

---

### Issue: Form validation not working

**Cause:** Browser not supporting HTML5 validation or JavaScript disabled

**Solution:**
1. Verify: Browser supports HTML5 (all modern browsers do)
2. Check: JavaScript is enabled (F12 → Console)
3. Test: Different browser
4. Verify: Input fields have `required` attribute
5. Check: Email field has `type="email"`

---

### Issue: Honeypot not preventing bots

**Solution:** This is expected - honeypot is working:
- Bot might still submit (honeypot at JavaScript level)
- Formspree also validates on server
- Multiple layers of protection
- Monitor Formspree dashboard for suspicious patterns
- Consider adding reCAPTCHA if bot submissions increase
