### Verify PHP is Available
1. Log into cPanel: https://hosting.hostafrica.net/cpanel
2. Look for: "PHP" or "PHP Info"
3. Click it and verify PHP version is 7.4 or higher
4. ✅ If you can see PHP info: deployment will work

### Verify Email is Configured
1. In cPanel: Find "Email" section
2. Verify: info@aurisnexus.co.za email exists
3. If not exists: Create it in cPanel
4. ✅ If email exists: mail() function will work

### Verify File Permissions
1. In cPanel File Manager
2. Upload any test .php file
3. Right-click → Properties
4. Check: Permissions are 644 or 755
5. ✅ If permissions are correct automatically: deployment will work
