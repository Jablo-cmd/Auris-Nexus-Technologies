## If Upload Fails

### Error: "Cannot Upload File"
- Solution: Check file size isn't corrupted
- Try: Download fresh copy of contact-submit.php from source

### Error: "File Not Found After Upload"
- Solution: Make sure you uploaded to public_html, not a subfolder
- Check: File is at same level as index.html, contact.html, services.html

### Error: "Still Returns 404 After Upload"
- Solution: Clear browser cache (Ctrl+Shift+Delete)
- Try: Open in new incognito/private window
- Check: File permissions are 644 (via File Manager properties)

### Error: "File Uploaded But Status Still 404"
- Solution: Contact HOSTAFRICA support
- Issue: PHP may not be enabled for your account
- Request: "Enable PHP execution for .php files in public_html"
