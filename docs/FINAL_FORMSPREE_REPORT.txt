## E. HONEYPOT STATUS

**Field Name:** website

**HTML Structure:**
```html
<div aria-hidden="true" class="hp-field">
  <label>Leave this empty</label>
  <input autocomplete="off" name="website" tabindex="-1" type="text"/>
</div>
```

**Protection Features:**
- ✅ Visually hidden from normal users (CSS class)
- ✅ Hidden from screen readers (aria-hidden="true")
- ✅ Removed from tab order (tabindex="-1")
- ✅ Autocomplete disabled
- ✅ No descriptive label (doesn't reveal purpose)
- ✅ Generic placeholder text ("Leave this empty")

**Bot Protection Mechanism:**
- Automated scripts see empty field and fill it
- If field contains any value on submission, likely bot
- Formspree and our JavaScript both validate honeypot
- Submission rejected/returns generic success (no email sent)

**Status:** ✅ PRESERVED AND FUNCTIONAL
