How a website project runs

  • Discovery. We agree what the site must achieve, which pages it needs and how visitors should contact you.
  • Design. Page structure first, then visuals in your brand, designed for phones before desktops.
  • Build. A fast, responsive site with clean headings and metadata so search engines can read it.
  • Launch and support. We go live with SSL, Google Maps and Analytics set up, then support you for 30 days.
